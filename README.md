# Heart Disease Prediction using Machine Learning

My first Machine Learning project! ❤️

This project uses Logistic Regression to predict a heart disease classification based on user-provided health-related features.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- StandardScaler
- Joblib
- Streamlit

## Model Performance
- Accuracy: Approximately 87%
- F1 Score: Approximately 87%

These scores reflect my model's evaluation results and do not guarantee an individual prediction.

## Run Locally

Install the required libraries:

pip install -r req.txt

Run the app:

streamlit run app.py

## Disclaimer
This project is for educational purposes only. It is not a medical diagnostic tool and should not be used to make healthcare decisions.
